# Sales Analysis

## About

This project is a Python exercise focused on analyzing sales data.

The program processes sales records and calculates important business indicators, such as total revenue, revenue by product, revenue by month, the product with the highest revenue, the month with the highest revenue, and the average revenue per sale.

The project was developed using Python fundamentals, without external data analysis libraries.

## Concepts Practiced

* Lists and tuples
* Dictionaries
* `for` loops
* Functions
* Conditional statements
* `sum()`
* `len()`
* `max()`
* Dictionary methods
* Data aggregation
* Basic sales analysis

## Features

The program calculates:

* Total revenue
* Revenue by product
* Product with the highest revenue
* Revenue by month
* Month with the highest revenue
* Average revenue per sale
