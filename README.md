# Python Fundamentos 🐍

Repositório criado para organizar meus estudos e exercícios de fundamentos de Python.

Este projeto representa minha evolução na programação e serve como base para meus
próximos estudos em análise de dados e ciência de dados.

## 📚 Conteúdos estudados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Listas
- Funções
- Validação de dados

## 📂 Organização

### 01 - Variáveis e Entrada
Exercícios relacionados a variáveis, entrada de dados e operações básicas.

### 02 - Condicionais
Exercícios utilizando `if`, `elif` e `else`.

### 03 - Loops
Exercícios utilizando `for`, `while` e `range()`.

### 04 - Listas
Exercícios relacionados à criação e manipulação de listas.

### 05 - Funções
Exercícios utilizando funções com `def` e `return`.

### 06 - Validação
Exercícios envolvendo validação e tratamento de entradas do usuário.

## 🎯 Objetivo

Fortalecer meus fundamentos de Python para posteriormente aplicar a linguagem
em projetos de análise de dados e ciência de dados.
