# Validação de Dados

Exercícios desenvolvidos para praticar validação de informações
fornecidas pelo usuário.

## 📚 Conteúdos

- `while`
- `len()`
- Operadores lógicos
- Validação de entrada
- Repetição até entrada válida
- Tratamento de diferentes tipos de dados

## 🎯 Objetivo

Aprender a impedir que dados inválidos sejam aceitos pelo programa
e desenvolver programas mais seguros e confiáveis.
