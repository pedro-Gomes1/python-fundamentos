# Listas em Python

Exercícios desenvolvidos para praticar a criação e manipulação
de listas em Python.

## 📚 Conteúdos

- Criação de listas
- `append()`
- Acesso por índice
- Iteração sobre listas
- Armazenamento de múltiplos valores
- Soma e média de valores

## 🎯 Objetivo

Aprender a armazenar e manipular conjuntos de valores utilizando listas.
