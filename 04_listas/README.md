# Listas em Python

Exercícios desenvolvidos para praticar o uso de listas em Python.

## 📚 Conteúdos praticados

- Criação de listas
- Armazenamento de valores
- `append()`
- Acesso aos elementos por índice
- Iteração sobre listas
- Percorrer listas com `for`
- Soma e média de valores
- Utilização de listas em outros cálculos

## 📝 Exercícios

### Cinco números
Programa que recebe cinco números, armazena os valores em uma lista e calcula a soma e a média.

### Exibição de intervalo
Programa que recebe dois números, armazena os valores em uma lista e utiliza os valores como início e fim de um intervalo.

### Soma de intervalo
Programa que utiliza os valores armazenados na lista para calcular a soma dos números de um intervalo.

## 🎯 Objetivo

Praticar a manipulação de listas e desenvolver lógica de programação utilizando Python.
