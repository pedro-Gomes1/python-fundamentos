# Funções em Python

Exercícios desenvolvidos para praticar a criação e utilização de funções.

## 📚 Conteúdos

- `def`
- Parâmetros
- `return`
- Reutilização de código
- Funções booleanas

## 🎯 Objetivo

Aprender a dividir programas em partes menores e reutilizáveis,
melhorando a organização e a manutenção do código.
